### 📊 ETF Tracker

An ETF monitoring system that tracks the fund flow of the **national team (Central Huijin)**.

* Monitors ETF holdings with a rolling fund-flow window and ranks the strongest inflows
* Multi-source data with graceful degradation: **Wind MCP → AKShare → mock**
* Auto-generates and archives daily Markdown reports
* Tech: **Python · pandas · Wind MCP · AKShare**

### 🔮 TrendCast Pro

A multi-horizon market direction prediction engine for **A-Share stocks, commodity futures and Forex**.

* Outputs **5-day (short) / 10-day (mid) / 20-day (long)** direction probabilities
* End-to-end pipeline: data collection → feature engineering → training → evaluation → export → REST service → report
* Dual evaluation: ML metrics (Accuracy / F1 / AUC) + financial metrics (win rate / Sharpe / profit-loss ratio / max drawdown)
* Adaptive learning with performance monitoring, drift detection and auto-retraining; serves predictions over **FastAPI (:8800)**
* Tech: **LightGBM · FastAPI · pandas · NumPy**

### 📉 Quant Strategy System

An AI-driven multi-strategy quantitative portfolio management system.

* Strategy stack: **Risk Parity · Core-Satellite · Momentum Timing · ML Direction Prediction · Hedge & Rebalance Linkage**
* Data source chain: **Wind MCP → iFinD → AKShare → local cache**
* Integrated LLM decision layer with local inference via **Ollama Qwen2.5**
* Tech: **Python · Streamlit · LightGBM / XGBoost · LangGraph**
